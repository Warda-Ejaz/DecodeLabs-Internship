# DecodeLabs-Internship Internship Projects 

Overview
This repository contains three comprehensive Data Science projects completed as part of the Data Science Industrial Training Program. These projects demonstrate practical applications of data preprocessing, machine learning, and customer analytics using industry-standard tools and techniques.
The primary objective of these projects is to develop a strong foundation in data cleaning, feature engineering, supervised learning, and unsupervised learning while following a structured data science workflow.

Project 1: Advanced EDA & Feature Engineering
Objective

The goal of this project is to transform raw and unstructured data into a clean, machine-learning-ready dataset through advanced exploratory data analysis and feature engineering techniques.

Key Tasks Performed
Data Cleaning
Identified missing values within the dataset.
Applied statistical imputation techniques using Mean Imputation.
Validated data consistency after preprocessing.
Outlier Treatment
Detected outliers using the Interquartile Range (IQR) method.
Reduced the impact of extreme values through Winsorization.
Feature Engineering

Created new predictive features to enhance the information available for machine learning models:

Study_Attendance
Assignment_Rate
Performance_Index
Skills Demonstrated
Data Cleaning
Missing Value Handling
Outlier Detection and Treatment
Feature Engineering
Exploratory Data Analysis (EDA)
Outcome

Successfully transformed a raw dataset into a structured and analysis-ready dataset suitable for machine learning applications.

Project 2: Fraud Detection Pipeline
Objective

The objective of this project is to build a supervised machine learning pipeline capable of detecting fraudulent transactions in an imbalanced dataset.

Key Tasks Performed
Data Preparation
Loaded and explored transaction data.
Separated features and target variables.
Handling Class Imbalance
Applied Synthetic Minority Oversampling Technique (SMOTE).
Balanced the distribution of fraudulent and non-fraudulent transactions.
Model Development

Implemented and evaluated multiple classification algorithms:

Logistic Regression
Built a baseline classification model.
Evaluated predictive performance.
Random Forest Classifier
Developed an ensemble-based classification model.
Compared performance against Logistic Regression.
Model Evaluation

Performance was measured using:

Precision Score
Recall Score
ROC-AUC Score

Accuracy was intentionally avoided due to the imbalanced nature of the dataset.

Skills Demonstrated
Supervised Machine Learning
Classification Algorithms
Class Imbalance Handling
Model Evaluation
Fraud Detection Techniques
Outcome

Developed a fraud detection pipeline capable of identifying suspicious transactions while emphasizing high-quality evaluation metrics suitable for real-world financial systems.

Project 3: Customer Segmentation Using PCA and K-Means
Objective

The purpose of this project is to discover hidden customer groups within retail data and translate these groups into meaningful business insights.

Key Tasks Performed
Data Preprocessing
Selected relevant customer attributes.
Standardized numerical features for clustering.
Dimensionality Reduction
Applied Principal Component Analysis (PCA).
Reduced data dimensions while preserving key information.
Cluster Analysis
Implemented K-Means Clustering.
Determined the optimal number of clusters using the Elbow Method.
Cluster Validation
Evaluated clustering quality using Silhouette Score.
Customer Persona Development

Translated mathematical clusters into actionable business personas, such as:

High-Value Customers
Budget-Conscious Customers
High-Spending Young Customers
Data Visualization
Visualized clusters in a two-dimensional PCA space.
Improved interpretability of customer segments.
Skills Demonstrated
Unsupervised Learning
PCA
K-Means Clustering
Cluster Validation
Customer Segmentation
Business Intelligence
Outcome

Successfully identified distinct customer groups and generated business-oriented insights that can support targeted marketing and customer engagement strategies.
